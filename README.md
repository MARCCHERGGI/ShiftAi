# Shift AI — free AI job prep for bartenders

**Live: [shiftai-six.vercel.app](https://shiftai-six.vercel.app)** · free for everyone · MIT

Paste a job link. An AI agent crew (scout → venue → menu → people → reviews → synthesis) researches the venue, then builds a tailored resume and runs a venue-specific mock interview. iOS-native UI, installable as an app.

**→ The app lives in [`shiftai/`](shiftai/) — full docs, self-host guide (one free key), and architecture there.**

`legacy/` is the previous single-page version, kept for history.
